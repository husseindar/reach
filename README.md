# Reach

A wholesale sourcing and buying tool for Amazon FBA. A personal project by Hussein Darwich, October 2026 to the present.

**Read about it here: https://husseindar.github.io/reach/**

I planned and specified Reach, then built it by directing AI coding agents. It finds UK wholesalers worth approaching, reads their price lists, matches each line to its Amazon listing and judges whether it's worth buying. Every supplier email, order and Amazon change waits for my sign-off.

This repo holds only that public page (`index.html`) and its screenshots, which use made-up sample data. The tool's code is private.
